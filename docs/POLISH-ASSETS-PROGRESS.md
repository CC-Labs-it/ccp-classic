# Presets and progress artwork provenance

Public source: [CCP at fe40ea7587ac0b09e47d0724e59d7178db3336da](https://github.com/CC-Labs-it/Conditioning-Control-Panel/tree/fe40ea7587ac0b09e47d0724e59d7178db3336da). GitHub repository metadata confirmed public visibility.

All 30 PNGs were read from the local client checkout, compared against the pinned public Git blob SHA1 and byte size, then copied byte for byte. No private assets, account data or server files are included. Original owner artwork is reused at the owner's request.

- 27 badge originals retain their stable IDs. The UI clips their central emblems so baked legacy captions do not replace the approved neutral localized names and requirements.
- Gentle uses hero_drift, Daily uses hero_default, Deep uses hero_deep. These are original public program hero masks.
- ProgramArt.cs describes white RGB with luminance in alpha. The panel applies their masks to accent gradients, retaining that source contract.
- Source PresetsTabView.xaml and MainWindow.Presets.cs supply the selected-card outline, rounded depth and hover treatment vocabulary.
- Static source artwork remains unchanged. A single attached-panel clock pans the masks and breathes unlocked artwork; hidden/minimized, Gentle, Reduced motion and Performance gates stop redraws. Visible panels continue while inactive.
- Decode size is bounded to256px for badges and512px for masks. The shared cache has at most32 images.
- PNGs follow existing binary gitattributes. No new binary extension or LFS rule is required.
